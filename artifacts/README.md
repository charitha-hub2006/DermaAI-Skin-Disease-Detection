# Artifacts Directory

This directory stores evaluation metrics, classification reports, confusion matrices, and loss/accuracy plots generated by `training/evaluate.py`.

## Contents

- `classification_report.json`: Precision, Recall, F1-Score, and Support for each skin disease category.
- `metrics_summary.json`: High-level test accuracy, macro F1, and weighted F1 metrics.
- `confusion_matrix.png`: Heatmap plot illustrating true vs. predicted classifications.
- `training_history.png`: Plots showing training and validation accuracy and loss over epochs.

These artifacts are referenced by the web application's **Model Info** page to show transparency into how the model was trained and evaluated.
