CNN Model Architecture & Specifications

Deep Convolutional Neural Network engineered for multi-class dermatological triage

{% if model_status.model_loaded %} Model Active & Serving {% else %} Model Unloaded {% endif %}

The classifier utilizes a multi-stage 2D Convolutional architecture designed with progressive spatial reduction and channel expansion. Each block combines \(3 \times 3\) convolutional filters, Batch Normalization for covariate shift mitigation, ReLU non-linearities, Max Pooling for translation invariance, and Dropout layers to prevent co-adaptation of feature detectors.

Input Dimensions 128 × 128 × 3
Optimization Algorithm Adam (\(\alpha=0.001\))
Loss Objective Categorical Crossentropy
Output Activation Softmax (7 Classes)

Layer (Type) Output Dimensions Operation Details
InputLayer (128, 128, 3) Raw RGB pixel tensor [0.0, 1.0]

Conv Block 4 (16, 16, 256) Conv2D(256, 3×3) + BatchNorm
GlobalAvgPool2D (256) Feature map condensation & parameter reduction
Dense Head (128) Fully-Connected ReLU + BatchNorm + Dropout(0.4)
Output Layer (7) Dense Softmax (Disease categorical probabilities)

Engineering Limitations & Future Enhancements

Current Architectural Limitations:
  • Resolution Trade-off: Resizing to \(128 \times 128\) pixels allows smooth CPU execution on laptops but suppresses fine microscopic pigment microstructures.
  • Class Distribution Bias: Clinical datasets have heavy class imbalances requiring continuous cost-sensitive or focal-loss adjustments.
  • Fitzpatrick Scale Representation: Datasets predominantly represent lighter skin phototypes (Types I-III); performance may degrade on darker skin tones without balanced multi-center cohorts.
Targeted Future Enhancements:
  • Explainable AI (Grad-CAM): Integrate Gradient-weighted Class Activation Mapping to highlight salient spatial regions guiding predictions.
  • Multimodal Fusion: Combine visual image tensors with patient metadata (age, sex, anatomic site, family history) via tabular neural networks.
  • Ensemble Architecture: Blend custom CNN predictions with fine-tuned MobileNetV3 and EfficientNet backbones for voting consensus.
