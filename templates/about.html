About the Project

Skin Disease Detection Using CNN is an end-to-end computer vision and software engineering capstone project designed to classify dermatoscopic skin lesions into diagnostic categories using deep learning.

Problem Statement

Skin cancers, particularly malignant melanoma, represent some of the fastest-growing oncological conditions globally. Early detection dramatically improves 5-year survival rates from under 25% to over 98%. However, access to experienced dermatologists is unevenly distributed, and visual triage under standard clinical light can result in diagnostic ambiguity. Automated Computer-Aided Diagnostic (CAD) systems using Convolutional Neural Networks offer the capability to provide rapid, objective second opinions to support clinical triage.

Project Objectives
  • Deep Feature Extraction: Build and train a high-capacity Convolutional Neural Network capable of learning hierarchical spatial representations (edges, textures, color gradients, and pigment network structures) directly from raw lesion pixels.
  • Preventing Data Leakage: Implement patient-level group splitting so that images from the same patient or lesion are never split across train and test sets.
  • Lightweight Local Deployment: Engineer a full-stack Flask web application capable of running locally on student hardware without dependency on paid cloud APIs.
  • Software Engineering Rigor: Apply formal SDLC practices, comprehensive automated test suites (pytest), input validation, defensive error handling, and structured architecture diagrams.

Viva Voce Preparation & Technical Q&A

High-yield questions frequently asked by academic faculty, external examiners, and evaluators during project defense.

Traditional ML algorithms require manual hand-crafted feature engineering (e.g., ABCD rules, GLCM texture analysis, color histograms), which are sensitive to lighting variations and human bias. CNNs perform end-to-end representation learning: early convolutional layers learn low-level primitives (edges, color boundaries), intermediate layers detect localized textures (pigment networks, dots, globules), and deeper layers capture high-level semantic shapes and lesion topologies.

In medical datasets like HAM10000, multiple photographs are often taken of the same patient or lesion under different angles or magnifications. If a random train/test split is applied, images of the same patient can appear in both training and testing partitions. The model would memorize patient-specific skin features rather than learning general disease pathology, producing artificially inflated test accuracy. We prevented this by grouping splits strictly by lesion_id/patient_id so no lesion ever spans across splits.

Softmax normalizes the raw real-valued output logits \((z_i)\) of the final dense layer into a valid categorical probability distribution where \(\sum_{j=1}^K p_j = 1\) and \(0 \le p_i \le 1\). This allows the application to report statistical confidence percentages for each diagnostic class.

We employ defense-in-depth:
  1. Filenames are strictly sanitized using werkzeug.utils.secure_filename.
  2. Extensions are strictly whitelisted to {'jpg', 'jpeg', 'png'}.
  3. File streams are parsed in memory using Pillow's Image.open().verify() to catch malicious binaries disguised with image extensions.
  4. Uploads are not permanently saved to the filesystem, eliminating remote code execution vectors.
  5. A 16 MB maximum content limit is enforced at the Flask WSGI level.

Skin disease datasets suffer from severe class imbalance (e.g., Melanocytic Nevi comprise >65% of samples, whereas Dermatofibroma or Vascular lesions comprise <3%). A naive model predicting 'Nevus' for every case could achieve ~67% accuracy while missing 100% of deadly Melanomas! Therefore, clinical evaluation requires Sensitivity (Recall), Specificity, Precision, F1-Score, and complete Confusion Matrix inspection.
